# EDA: Exploratory Data Analysis

## Guide

- 数据长什么样：前几行数据和各列的类型、缺失情况 `train.head()`, `train.info()`
- 缺失值多不多，如何处理缺失值（填充、删除等）
- 目标变量分布，正负样本的比例，处理类别不平衡 (Class Imbalance)
- 特征与目标的关系，用 groupby 和绘图（分析不同进站决策下，圈速、轮胎寿命等特征是否有明显差异）

- 带有时序特征的 tabular 分类问题
- 时序数据 ✅
- 空间数据 ❌

| Column                   | Mean                                               |
| ------------------------ | -------------------------------------------------- |
| `id`                     | 行号，无意义                                       |
| `Driver`                 | 车手名称                                           |
| `Compound`               | 轮胎配方（如 Soft 软胎、Medium 中性胎、Hard 硬胎） |
| `Race`                   | 比赛名称（如 Monaco GP）                           |
| `Year`                   | 比赛年份（2022-2025）                              |
| `PitStop`                | 当前圈是否是进站圈（0/1）                          |
| `LapNumber`              | 当前是第几圈                                       |
| `Stint`                  | 每进一次站，Stint +1                               |
| `TyreLife`               | 当前轮胎已经跑了多少圈（换胎后从 0 开始计）        |
| `Position`               | 当前排名（第几名）                                 |
| `LapTime (s)`            | 当前圈用时（秒）                                   |
| `LapTime_Delta`          | 圈速变化（和前一圈的差值，负数 = 变快）            |
| `Cumulative_Degradation` | 累计轮胎衰退程度                                   |
| `RaceProgress`           | 比赛进度（0 = 开始，1 = 结束）                     |
| `Position_Change`        | 排名变化（正数 = 上升）                            |
| `PitNextLap`             | 目标：下一圈是否会进站（0/1）                      |

- 直觉
- 轮胎用越久（`TyreLife` 越大）、圈速变慢（`LapTime_Delta` 正值）、轮胎衰退越严重，越可能进站
- 时序数据，同一个车手之前表现，会影响当前表现
- 同一车手在前几圈的状态（轮胎衰退程度、圈速变化趋势）确实会影响后续是否进站

## Column

- 身份标识类

| 字段     | 含义                     | 对进站的影响                                                                                           |
| -------- | ------------------------ | ------------------------------------------------------------------------------------------------------ |
| `Driver` | 车手编号（如 D109）      | 不同车手的驾驶风格、轮胎管理能力不同，有人开得激进磨损快，有人温和省胎                                 |
| `Race`   | 比赛名称（如 Monaco GP） | 不同赛道特性差异极大——摩纳哥是街道赛，弯多、超车难，进站策略保守；蒙扎是高速赛道，超车容易，进站更灵活 |
| `Year`   | 年份（2022-2025）        | 规则、轮胎配方每年可能调整，影响整体进站策略趋势                                                       |

- 当前状态类（核心特征）

| 字段                     | 含义                   | 对进站的影响                                                                                                                                                                     |
| ------------------------ | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Compound`               | 轮胎配方               | **最关键特征之一**。Soft（软胎）：抓地力强但磨损快，寿命短；Medium（中性胎）：平衡；Hard（硬胎）：耐磨但抓地力弱。软胎跑几圈就得换，硬胎能撑很久                                 |
| `TyreLife`               | 当前轮胎已跑圈数       | **核心特征**。轮胎是消耗品，每跑一圈都会衰退。TyreLife 越大 → 轮胎越旧 → 抓地力越差 → 越可能进站。通常软胎 ~15 圈、硬胎 ~30 圈就该换了                                           |
| `LapNumber`              | 当前第几圈             | 比赛早期一般不急着进站；接近比赛尾声时，如果轮胎还撑得住就不会换了（换新胎也追不回时间）                                                                                         |
| `LapTime (s)`            | 当前圈速（秒）         | 圈速变慢说明轮胎衰退严重、抓地力下降，是进站的信号                                                                                                                               |
| `LapTime_Delta`          | 和上一圈的圈速差       | **趋势指标**。正值 = 这一圈比上一圈慢，说明轮胎在加速衰退。持续变慢是进站的强信号                                                                                                |
| `Stint`                  | 当前是第几段 stint     | 两次进站之间的连续圈数叫一个 stint。Stint=1 是第一段（比赛开始），Stint=2 是换过一次胎之后。Stint 越大说明已经进过多次站了                                                       |
| `RaceProgress`           | 比赛进度（0→1）        | 比赛刚开始（0.1）几乎不会进站；快结束（0.9）如果轮胎够用也不会进站；中间阶段（0.3-0.7）是进站高峰期                                                                              |
| `Position`               | 当前排名（第 1-20 名） | 排名影响策略：领先的车手可以按自己节奏进站；落后的可能采取 "undercut"（提前进站用新胎优势超车）或 "overcut"（晚进站）                                                            |
| `Position_Change`        | 排名变化（正=上升）    | 如果你正在超车、位置在上升，可能不想进站打断节奏；如果位置在掉，可能需要用进站换胎来翻盘                                                                                         |
| `Cumulative_Degradation` | 累计轮胎衰退           | 一个综合指标，数值越大（或越负）说明轮胎衰退越严重，越需要换胎                                                                                                                   |
| `PitStop`                | 当前圈是否正在进站     | 如果这一圈已经在进站了（=1），那 `PitNextLap` 大概率是 0（刚换完胎不会再进）。这是一个**强特征但可能有数据泄露风险**——比赛中你只能知道过去是否进站，不知道 " 当前圈 " 是否在进站 |

- 目标变量

| 字段         | 含义                        |
| ------------ | --------------------------- |
| `PitNextLap` | **下一圈**是否会进站（0/1） |

## Business Background

- F1赛车
- 比赛跑固定圈数（比如 50-70 圈，取决于赛道长度），谁先跑完所有圈谁赢
- 比赛中必须使用至少两种不同配方的轮胎（规则强制），所以至少要换一次胎
- 换胎是在**维修区（pit lane）**完成的，所以叫"进站（pit stop）"

- 虽然规则只要求换一次，但比赛中经常换 2-3 次，原因是：
- 软胎磨损太快，撑不到比赛结束
- 换新胎后圈速明显更快，用时间优势超车（叫 undercut 策略）
- 比赛中遇到安全车（safety car），全场减速，这时候进站损失的时间最少，很多车手会趁机换胎

- 车队面临的是一个时间优化问题
- 不换胎：圈速越来越慢，每圈损失 0.5-1 秒
- 换胎： 一次损失 20-25 秒，但新胎圈速快回来
- 什么时候换？当"继续用旧胎累计损失的时间" > "进站损失的时间"
